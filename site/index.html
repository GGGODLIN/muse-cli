muse-cli

Talk to your personal muse.ai AI agent from the terminal.

View on GitHub PyPI

Install

uv tool install muse-cli      # or: pipx install muse-cli / pip install muse-cli

One-time login borrows the session you already have in Chrome (details), then no browser needed:

muse-cli auth export
muse-cli status

Agents driving agents

muse-cli ships an agent skill, so a coding agent can drive your Muse agent for you. Here is a live session: prompt a Droid worker, it activates the skill, runs muse-cli status and muse-cli goals, and reports back.

Usage

muse-cli threads                                  # main chat + side chats
muse-cli history --limit 5                        # recent messages
muse-cli send "summarize my unread" --wait 120    # send + wait for reply
muse-cli watch --timeout 60                       # tail live agent events

muse-cli feed --limit 5
muse-cli goals
muse-cli ideas
muse-cli idea-exec <idea-id>                      # agent acts on the idea

muse-cli session-start --title "trip planning"    # new side chat
muse-cli raw <method> --body '{}'                 # escape hatch: 258 methods

Every command prints JSON. Pipe it anywhere:

muse-cli send "what's on my calendar today?" | jq -r .reply.text

How it works

🔐 HTTPS auth

Borrows your Chrome login once, then fetches fresh access and gateway tokens on every run.

🔒 Noise-XX transport

Speaks the app's own gateway protocol: an encrypted Noise-XX WebSocket straight to your personal VM.

📜 JSON everything

Every command prints JSON, so it pipes into jq, cron jobs, and other AI agents.

🤖 Agent skill included

Installs a skill file so coding agents can check, message, and automate your Muse agent.

🕳️ 258-method escape hatch

Named commands for the common tasks, plus muse-cli raw for every gateway method.

🔄 Self-updating

Notices new PyPI releases once a day in a terminal; upgrade with muse-cli update.
